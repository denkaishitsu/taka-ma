あなたは分類器です。以下の「返信文」を読み、2 つの判定だけを行ってください。

1. `claims_progress` — 送信者（アシスタント）自身が**いま進行中・実行中の作業を
   抱えていると主張しているか**。
   - true の例: 「作業中です」「更新を実施しています」「処理を進めています」「完了次第お伝えします」
     「もう少しお待ちください」「Working on it」「The update is in progress」
   - false の例: 質問・聞き返し・情報の要求、一般的な説明や知識の回答、
     これから着手する意思の確認（「着手してよいですか？」）

2. `claims_state` — 送信者自身が**過去の実行状態を事実として述べているか**
   （実行した/していない、完了した/していない、コミット・マージ・push の済/未 等）。
   - true の例: 「コミットやマージは行っておりません」「push は完了しました」
     「設計書の作成は行っておりません」「The merge has been completed」
   - false の例: 実行状態に触れない返信、これからの予定の説明、ユーザーへの質問

- 言語は問いません（日本語・英語・その他すべて対象）。
- 表現の言い回し・活用形は問いません。**意味**で判定してください。
- 両方 true になることもあります。
