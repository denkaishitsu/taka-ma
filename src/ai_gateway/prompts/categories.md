execution と depth は独立した 2 軸で判定する。

### execution 軸

- **inline**: 純生成・単発のプロンプト応答で完結するもの（単純な質問応答・テンプレート/設定ファイル/定型文面の生成）。ファイル読み取りやフォーマット変換は inline に含めない（ツールが要るため agent）
- **agent**: ツール使用・探索・試行錯誤・対話反復を伴うもの（ファイルの読み書き/実行/エラー修正・テスト実行・コード生成/バグ修正・要件定義/設計/解析）。判断に迷うものは全て agent

### depth 軸（agent の場合のみ。モデル階梯を決める）

- **shallow**: 浅く定型的で 1〜数手で終わる
- **deep**: 深い設計・難所。探索と試行錯誤が本質的なもの
- 判断がつかなければ省略する（inline は常に不問・省略してよい）
